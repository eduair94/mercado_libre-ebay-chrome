📋 Instrucciones de Prueba

  1. Carga la extensión en Chrome (Desarrollador → Cargar extensión sin empaquetar)
  2. Haz clic en el ícono de la extensión para abrir el popup
  3. Verifica que todos los toggles funcionen correctamente
  4. Cambia el tamaño del texto y observa el feedback visual
  5. Prueba el cambio de idioma (español ↔ portugués)
  6. Guarda la configuración y recarga la extensión para verificar persistencia

⚠️ Notas de Desarrollo

  • La extensión usa CDN de Tailwind CSS para simplicidad en desarrollo
  • Los archivos de idioma están en la carpeta _locales/
  • Las configuraciones se guardan usando chrome.storage.sync
  • El popup tiene un ancho mínimo de 380px para mejor UX
